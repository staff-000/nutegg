1. Title Verdict: Provide a single, direct sentence that resolves the core question posed in the title or introduction.
2. Core Summary: Summarize the main concepts in plain language using a maximum of 3 bullet points.
3. Mind Map: Construct a hierarchical concept tree capturing the core mental model or argument flow (up to 3 levels deep). Each node must have a concise `name` and informative explanatory `detail`. When the content presents an explicit enumeration, numbered list, or step-by-step sequence (e.g., "6 ways to...", "first step, second step..."), preserve EVERY item in order as its own sibling node without capping node count, and include its number in the node `name` (e.g., `"1. ..."`). Use an optional `time` per Mind Map node for an exact supporting timestamp in video transcripts. Omit it for untimestamped sources; never invent a time. For text nodes, include `sources` with an original heading/location hint and distinctive verbatim `quote`; add exact `sourceId` when referencing a captured discussion item.
