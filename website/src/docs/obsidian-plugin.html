Obsidian Plugin Setup & Configuration

The NutEgg Obsidian plugin hosts the local sync server, manages AI communication, matches incoming content to your knowledge trees, and maintains your vault files.

Installation

Option 1: Obsidian Community Plugins (Recommended)

NutEgg is officially listed in the Obsidian Community Plugins directory:

  1. In Obsidian, open Settings → Community plugins.
  2. Ensure Restricted mode is turned off, then click Browse.
  3. Search for NutEgg (or visit NutEgg on Obsidian Community Plugins).
  4. Click Install, then click Enable.

Option 2: Manual Installation

  1. Download main.js, manifest.json, and styles.css from the NutEgg Obsidian Plugin Releases.
  2. In your Obsidian vault, open .obsidian/plugins/ (show hidden folders in your OS if needed).
  3. Create a new directory named nutegg and place the three files inside: 
    your-vault/.obsidian/plugins/nutegg/
├── main.js
├── manifest.json
└── styles.css
  4. In Obsidian, open Settings → Community plugins, click Reload, and toggle NutEgg on.

Option 3: Using BRAT

  1. Install the BRAT community plugin in Obsidian.
  2. Go to Settings → BRAT → Add Beta plugin.
  3. Enter staff-000/nutegg-obsidian-release and click Add Plugin.
  4. Enable NutEgg once installed.

AI Provider Configuration

NutEgg puts you in complete control of your AI model, local endpoints, and keys. In Obsidian, go to Settings → NutEgg and toggle Developer mode:

  • Local LLM (Ollama, LM Studio, llama.cpp, vLLM):
    • API Type: Select either OpenAI-compatible (used by LM Studio, llama.cpp, vLLM, and Ollama /v1) or Ollama Native (direct /api/chat).
    • Zero Model Configuration: No need to select or specify a model—NutEgg communicates directly with your local server's active loaded model.
    • API Key (Optional): Only needed if your local proxy or server requires an authorization bearer token.
  • Cloud Providers & OpenRouter (3-Tier Setup):
    • 1. AI Provider: Anthropic, OpenAI, Google Gemini, DeepSeek, Kimi, Qwen, Zhipu, or OpenRouter.
    • 2. Model Family: Choose the architecture/series (e.g. Claude Sonnet / Opus / Haiku, GPT-5 / o-Series / GPT-4o, Gemini 2.5 / 2.0, DeepSeek V3 / R1, Kimi K3, GLM-5, Qwen3).
    • 3. Model Version: Select the latest model version or enter any custom model tag.
    • API Key: Enter your provider API key. Securely stored locally in your Obsidian vault.
  • Connection & Credit Monitor: Instantly test local runner connectivity or check remaining cloud credit balance with 1 click.

Local Sync Server & Security

When the plugin is enabled, it automatically boots a background HTTP listener on 127.0.0.1:27123.

🔒 Privacy & Security Assurance

The local server binds strictly to the localhost loopback address (127.0.0.1). It enforces strict CORS origin validation to prevent arbitrary web pages from accessing your vault, and includes a 25MB payload ceiling to protect system memory.

Workflow & Prompt Customization

NutEgg powers its AI analysis through modular, editable Markdown prompts stored directly in your vault under nutegg/_workflow/:

  • Editable Templates: Customize prompts for content analysis, egg comparison, routing, and follow-ups.
  • Non-Destructive Updates: When NutEgg releases updated prompt templates, your customized workflows are automatically preserved without being overwritten.
