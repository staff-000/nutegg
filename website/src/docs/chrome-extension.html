Chrome Extension Setup & Usage

The NutEgg Chrome extension lives in your browser's side panel, providing on-demand content extraction, YouTube mind maps with clickable timestamps, and one-click capture to Obsidian.

Installation

Option 1: Chrome Web Store (Recommended)

Install NutEgg with one click directly from the official Chrome Web Store:

  1. Visit the NutEgg Chrome Web Store page.
  2. Click Add to Chrome.
  3. Click the puzzle piece icon in Chrome's toolbar and pin NutEgg for convenient side panel access.

Option 2: From GitHub Release (.zip)

  1. Download the latest nutegg-chrome-extension-*.zip from the Releases page.
  2. Unzip the archive to a local folder on your computer.
  3. Open Google Chrome and go to chrome://extensions.
  4. Toggle Developer mode on in the upper-right corner.
  5. Click Load unpacked and select the unzipped directory containing manifest.json.
  6. Click the puzzle icon in the Chrome toolbar and pin NutEgg for easy access.

Side Panel Workflow

Clicking the NutEgg extension icon opens Chrome's side panel:

  • Auto-Extraction: As you browse, NutEgg detects the active tab (YouTube video, Twitter/X thread, or blog post) and extracts its text and structure.
  • Content Refresh (🔄): Click the refresh button in content preview to re-extract the page on dynamic single-page apps without unexpectedly redirecting away from the preview.
  • Target Egg Selector: In content preview, choose target knowledge eggs or use "Target eggs (auto-select by default)" to let AI match relevant vault trees automatically.
  • Analysis Modes:
    • Full Mode: Evaluates content and immediately runs knowledge matching against matching eggs in a single streamlined workflow.
    • Preview Mode: Generates the Stage 1 overview first (summary, mind map, Q&A, discussion), letting you inspect or adjust target eggs before running egg knowledge analysis on demand.
  • Status Indicator: A green dot indicates a healthy connection to your local Obsidian server (127.0.0.1:27123). If red, ensure Obsidian is running with the NutEgg plugin enabled.

YouTube Integration & Smart Navigation

On YouTube video pages, NutEgg extracts:

  • Full Captions & Transcripts: Automatic high-accuracy extraction from creator and auto-generated transcripts.
  • Mind Map with Clickable Timestamps: Instant breakdown with clickable timestamp buttons that seek your active YouTube video player directly to that segment. When timestamps are present, redundant source tags are hidden to keep the tree clean.
  • Q&A with Timestamp Jumping: Ask any question about the video in natural language; NutEgg provides cited answers with clickable timestamp pills that jump straight to the source moment in video playback.
  • Anti-Clickbait Verdict: An objective 1-sentence answer to the video title's premise, letting you skip fluff immediately.

Text In-Page Source Navigation

When reading articles, blogs, or forums:

  • 📍 Jump to Source: Text mind-map nodes and Q&A citations include source tags. Clicking a source tag automatically scrolls the live web page to the exact matching paragraph or quote and briefly highlights it with an outline.
  • Comment Navigation: On discussion pages (Reddit, Zhihu, etc.), clicking source citations scrolls directly to the specific comment or answer.

Discussion Analysis & Community Perspectives

NutEgg analyzes public comments across YouTube, Reddit, Twitter/X, Zhihu, and forums:

  • Topic & Stance Breakdown: Summarizes core debate points with stance badges (agree 👍, disagree 👎, mixed 🤔, neutral ⚖️) and reaction metrics.
  • Extra Insights: High-value comments containing evidence, caveats, or unique experiences are preserved as concise extra insights.

Chrome-Only Standalone Mode (No Obsidian Required)

Don't have Obsidian installed or currently open? NutEgg works completely standalone inside Google Chrome!

⚡ Fast Web Reading Without Note Overhead

NutEgg is designed first and foremost as an ultra-fast web reading companion. You can extract, summarize, generate mind maps, and ask questions about any article or YouTube video directly in Chrome without ever touching a note vault.

Features Available in Chrome Standalone:

  • 🎯 Instant Anti-Clickbait Verdict: An objective 1-sentence answer to the headline's question.
  • 📝 Executive 3-Sentence Summary: High-density takeaways extracted from any long article or video.
  • ⏱️ Mind Map with Clickable Timestamps & Seeking: Jump to key video segments with one click.
  • 💬 Video Q&A & Timestamp Jumping: Ask questions and click cited timestamp pills to scrub video playback directly to that segment.
  • 🧠 Collapsible Mind Maps: Multi-tier interactive thought trees breaking down core ideas visually.
  • 🌐 50+ Languages Support: Extract and translate foreign-language content on the fly.

How to Configure Chrome-Only Mode:

  1. Right-click the NutEgg extension icon in Chrome's toolbar and select Options.
  2. Select your preferred AI provider (e.g., Google Gemini, OpenAI, Claude, DeepSeek, or OpenRouter) and enter your API key.
  3. Click Save. You're ready to analyze any page!

Obsidian Connection & AI Execution Modes

When you connect the Chrome extension to the optional NutEgg Obsidian plugin, Chrome seamlessly adapts depending on the selected execution mode:

🔒 API Key Security: Keys Never Leave Chrome

In Connected API Mode, your API keys stay strictly inside Chrome's secure extension storage. Obsidian manages knowledge templates and vault indexing, but delegates AI inference back to Chrome over an authenticated local WebSocket. Chrome makes the provider API call locally and returns only the generated text.

Execution Mode Where AI Runs Credentials Used
Chrome-Only Directly inside Chrome API key configured in Chrome Options
Connected API Mode Chrome (delegated via local WebSocket by Obsidian) API key in Chrome (keys never sent to Obsidian)
Shared Subscription Mode Inside Obsidian (via local CLI or ChatGPT OAuth) Zero API keys (uses Codex, Claude Code, Antigravity, or ChatGPT)

Multi-Profile Chrome Support

NutEgg supports multiple Chrome browser profiles (e.g. Personal and Work) connecting concurrently to the same Obsidian vault. Each Chrome profile retains its own provider, model, and API key independently. Connecting or switching execution modes never leaks or overwrites API keys between profiles.

Offline & Disconnect Recovery

If Obsidian is closed while connected mode is enabled, NutEgg displays a clear status light and gives you a one-click "Use Chrome mode instead" option. This lets you immediately continue reading and asking questions using your Chrome API setup without interruption or quota risk.

Configuration & Live Synchronization

NutEgg includes real-time synchronization between the extension Options and active side panels:

  • Content Section Controls: Customize which sections are extracted and analyzed by default (Content, Summary, Mind Map, Q&A, Knowledge Entries, and Discussion) in the Options page.
  • Live Settings Sync: Changing your analysis models, enabled output sections, or server settings immediately updates all open side panels without requiring a page refresh.
  • Custom Server Port: If default port 27123 conflicts with another service, open extension Options, adjust the port (e.g. 28123), and test the connection.
