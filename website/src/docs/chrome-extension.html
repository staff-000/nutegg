Chrome Extension Setup & Usage

The NutEgg Chrome extension lives in your browser's side panel, providing on-demand content extraction, YouTube chapter maps, and one-click capture to Obsidian.

Installation

Option 1: Chrome Web Store (Recommended)

Install NutEgg with one click directly from the official Chrome Web Store:

  1. Visit the NutEgg Chrome Web Store page.
  2. Click Add to Chrome.
  3. Click the puzzle piece icon in Chrome's toolbar and pin NutEgg for convenient side panel access.

Option 2: From GitHub Release (.zip)

  1. Download the latest nutegg-chrome-extension-*.zip from the Releases page.
  2. Unzip the archive to a local folder on your computer.
  3. Open Google Chrome and go to chrome://extensions.
  4. Toggle Developer mode on in the upper-right corner.
  5. Click Load unpacked and select the unzipped directory containing manifest.json.
  6. Click the puzzle icon in the Chrome toolbar and pin NutEgg for easy access.

Side Panel Workflow

Clicking the NutEgg extension icon opens Chrome's side panel:

  • Auto-Extraction: As you browse, NutEgg detects the active tab (YouTube video, Twitter/X thread, or blog post) and extracts its text and structure.
  • Status Indicator: A green dot indicates a healthy connection to your local Obsidian server (127.0.0.1:27123). If red, ensure Obsidian is running with the NutEgg plugin enabled.
  • Retry Button (🔄): If content loading ever gets stuck on dynamic single-page apps, click the refresh button to trigger a fresh extraction.

YouTube Integration & Smart Navigation

On YouTube video pages, NutEgg extracts:

  • Full Captions & Transcripts: Automatic high-accuracy extraction from creator and auto-generated transcripts.
  • Interactive Chapter Map: Instant breakdown with clickable timestamp buttons that seek your active YouTube video player directly to that segment.
  • Q&A with Timestamp Jumping: Ask any question about the video in natural language; NutEgg provides cited answers with clickable timestamp pills that jump straight to the source moment in video playback.
  • Interactive Mind Maps: Collapsible hierarchical thought trees visualizing core arguments and sub-points.
  • Anti-Clickbait Verdict: An objective 1-sentence answer to the video title's premise, letting you skip fluff immediately.

Chrome-Only Standalone Mode (No Obsidian Required)

Don't have Obsidian installed or currently open? NutEgg can run completely standalone inside Google Chrome!

⚡ Fast Web Reading Without Note Overhead

Standalone mode lets you use NutEgg as a rapid web-reading and video comprehension tool without creating or managing vault files.

Features Available in Chrome Standalone:

  • 🎯 Instant Anti-Clickbait Verdict: An objective 1-sentence answer to the headline's question.
  • 📝 Executive 3-Sentence Summary: High-density takeaways extracted from any long article or video.
  • ⏱️ Interactive Chapter Maps & Seeking: Jump to key video segments with one click.
  • 💬 Video Q&A & Timestamp Jumping: Ask questions and click cited timestamp pills to scrub video playback directly to that segment.
  • 🧠 Collapsible Mind Maps: Multi-tier interactive thought trees breaking down core ideas visually.
  • 🌐 50+ Languages Support: Extract and translate foreign-language content on the fly.

How to Enable Standalone Mode:

  1. Right-click the NutEgg extension icon in Chrome's toolbar and select Options.
  2. Scroll to Standalone Mode (Optional) and check "Use Chrome-only AI (when Obsidian is offline)".
  3. Select your preferred AI provider (e.g., Google Gemini, OpenAI, Claude, DeepSeek, or OpenRouter) and enter your API key.
  4. Click Save.

Tip: Whenever you launch Obsidian, NutEgg automatically pairs with it to enable Stage 2 vault knowledge matching. When Obsidian is closed, NutEgg gracefully falls back to Chrome-only mode.

Configuration & Live Synchronization

NutEgg includes real-time synchronization between the extension Options and active side panels:

  • Live Settings Sync: Changing your analysis models, enabled output sections, or server settings immediately updates all open side panels without requiring a page refresh.
  • Custom Server Port: If port 27123 conflicts with another service, open extension Options, adjust the port (e.g. 28123), and test the connection.
