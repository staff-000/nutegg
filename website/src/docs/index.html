Overview & Core Concepts

NutEgg is a local-first system designed to bridge the gap between passive web browsing and active knowledge curation in Obsidian.

The Metaphor

NutEgg structures your information flow using a simple three-part metaphor:

  • 🌰 The Nut (Raw Capture): The raw web page, tweet thread, or YouTube transcript extracted from the browser. Nuts are archived untouched with full metadata into nutegg/_raw/ in your vault.
  • 🥚 The Egg (Knowledge Tree): A living, structured markdown note in your vault representing a domain of knowledge (e.g., ai_architecture.md, invest_strategy.md).
  • 🐣 The Hatch (Synthesis & Delta): When content is analyzed, the AI matches it against your eggs, identifies what is novel compared to what is already documented, and weaves new insights into your egg.
💡 Why NutEgg Exists

Most web clippers dump raw articles into your vault, creating an unorganized graveyard of unread bookmarks. NutEgg checks novelty against your existing knowledge tree upfront, so you immediately know if an article is worth your time or if it's just repeating concepts you already know.

Flexible Operating Modes

NutEgg can be used in two flexible modes depending on your setup:

  • 📱 Standalone Mode (Chrome-Only): No Obsidian installation required. By entering your AI API key in Chrome Extension Options, NutEgg functions as a fast, standalone reading and navigation assistant directly inside your browser side panel:
    • 🎯 Instant Anti-Clickbait Title Verdict
    • 📝 Executive 3-sentence summary & core takeaways
    • ⏱️ Interactive YouTube Chapter Maps with jump-to-time buttons
    • 💬 Natural-language Video Q&A with cited timestamp pills
    • 🧠 Collapsible hierarchical Mind Maps
    • 🌐 Multi-source extraction and translation in 50+ languages
  • 💎 Connected Mode (Chrome + Obsidian): Pairs your browser with the local Obsidian companion plugin (127.0.0.1:27123). Unlocks full 2-stage novelty evaluation against your vault's _index.md knowledge trees, delta synthesis, and automatic note archiving into nutegg/_raw/ and egg files.

System Architecture

NutEgg consists of two decoupled components that communicate locally:

  1. Chrome Extension: Lives in Chrome's side panel. Interacts with the active tab, extracts text and video transcripts, runs standalone AI or forwards to Obsidian, and displays interactive summaries, mind maps, and Q&A.
  2. Obsidian Plugin: Runs a lightweight HTTP server on 127.0.0.1:27123. Connects to your chosen AI provider using your own API key, reads your vault's _index.md, and saves files directly to disk.
Chrome Extension (Side Panel)
         │
         ├── [Standalone Mode] Local Chrome AI Processing (Fast Summaries, Q&A, Mind Maps)
         │
         └── [Connected Mode] HTTP /analyze + /confirm (127.0.0.1:27123)
                 ▼
         Obsidian Plugin (Local Server)
                 ├── Evaluates against vault/nutegg/_index.md
                 ├── Queries AI Provider (Gemini / Claude / OpenAI / Local LLMs)
                 └── Writes to vault/nutegg/_raw/ and vault/nutegg/<egg>.md

Quick Start Roadmap

  1. Install the Obsidian Plugin via Community Plugins and configure your AI API key (see guide).
  2. Install the Chrome Extension from Chrome Web Store (see guide).
  3. Define your first knowledge topics in _index.md and start hatching!
