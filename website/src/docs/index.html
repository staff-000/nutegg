Overview & Core Concepts

NutEgg is a free, open-source Chrome extension that helps you decide what's worth reading—and understand it faster. It lives in Chrome's side panel and works on articles, threads, and YouTube videos. An optional Obsidian plugin turns what you read into a growing knowledge vault.

What You Get in Chrome

Install the extension, enter your AI API key (or point it at a local model) in Options, and NutEgg works right away—no account, no extra apps:

  • 🎯 Instant Anti-Clickbait Title Verdict
  • 📝 Executive 3-sentence summary & core takeaways
  • 🧠 Collapsible hierarchical Mind Maps, with clickable timestamps for YouTube
  • 💬 Natural-language Q&A with cited timestamp pills and in-page source links
  • 🔍 Dual-scope questions: strictly within the page, or beyond it for fact-checking
  • 🗣️ Comment-section digests for YouTube, Reddit, and forums
  • 🌐 Multi-source extraction and translation in 50+ languages
💡 Why NutEgg Exists

Too much of the web is padded videos, clickbait headlines, and AI-inflated articles. NutEgg answers the headline upfront and tells you honestly whether the content is worth your time—so you only spend attention where it pays off.

Optional: Add Obsidian

If you keep notes in Obsidian, install the companion plugin to connect the extension to your vault (127.0.0.1:27123). This adds 2-stage novelty evaluation against your vault's _index.md knowledge trees, delta synthesis, and automatic note archiving into nutegg/_raw/ and egg files. Everything in Chrome keeps working with or without it.

The Metaphor

With Obsidian connected, NutEgg structures your information flow using a simple three-part metaphor:

  • 🌰 The Nut (Raw Capture): The raw web page, tweet thread, or YouTube transcript extracted from the browser. Nuts are archived untouched with full metadata into nutegg/_raw/ in your vault.
  • 🥚 The Egg (Knowledge Tree): A living, structured markdown note in your vault representing a domain of knowledge (e.g., ai_architecture.md, invest_strategy.md).
  • 🐣 The Hatch (Synthesis & Delta): When content is analyzed, the AI matches it against your eggs, identifies what is novel compared to what is already documented, and weaves new insights into your egg.

System Architecture

NutEgg has one core component and one optional companion:

  1. Chrome Extension: Lives in Chrome's side panel. Extracts text, comments, and video transcripts. In standalone mode or connected API mode, it executes AI calls locally using your configured provider and API key—ensuring your API keys never leave the browser.
  2. Obsidian Plugin (optional): Runs a local sync and coordinator service on 127.0.0.1:27123. Reads your vault's _index.md, manages prompt templates in _workflow/, and archives captured knowledge to disk. It supports:
    • Connected API Mode (Default): Coordinates knowledge matching, delegating AI inference to Chrome via an authenticated local WebSocket (keys never sent to Obsidian).
    • Shared Subscription Mode: Runs inference locally via ChatGPT sign-in (OAuth) or developer CLI tools (Codex, Claude Code, Antigravity) with zero API keys needed.

Quick Start Roadmap

  1. Watch the 🎬 NutEgg Promo Video for a 1-minute visual walkthrough.
  2. Install the Chrome Extension from Chrome Web Store and add your AI key in Options (see guide).
  3. Open the side panel on any article or YouTube video and click Analyze. That's it!
  4. Optional: Install the Obsidian Plugin (see guide) and define your first knowledge topics in _index.md to start hatching.
